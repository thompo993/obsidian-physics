# [[Stem Workflow for Physics in obsidian ]]
This workflow and vault is designed for seamless work for a physics based stem degree, the idea is to allow for:
- lecture note taking
- literature reading and referencing
- academic writing
- coding 
- lab work (dry lab only)
- syncing all of this to the cloud such that it is not lost

## Tools you should be aware of: 
- Overleaf - A tool that you will use to write all of your academic papers, lab reports, coding reports etc. https://en.wikipedia.org/wiki/Overleaf
- Zotero - A reference manager that works well with obsidian and Overleaf 
- GitHub - A version control software that you will use for coding projects

## How to setup: 
### 1. Git For Obsidian:
Git for obsidian has plenty of documentation explaining how to set up a vault with git version control https://publish.obsidian.md/git-doc/Start+here.

Personally, I found Tom Peppercorns video https://www.youtube.com/watch?v=ImrLbomFYA0 extremely useful, the only difference is I used a fine grained PAT with the following permissions: 
- Read access to metadata
-  Read and Write access to code, commit statuses, merge queues, and pull requests
This is because I did not want a global permanent PAT for my GitHub to be around (security risk).  I set Git to Commit-and-sync every minute, and named my directory that has all of my notes that I want to be added to Git as "master"

The other thing I did is hotkey "Git: Commit-and-sync and then close Obsidian" to `ctrl + alt + s` as you can loose small amounts of progress if you forget to commit and sync before closing obsidian, so made it a habit to use this to close Obsidian instead of any other way of closing Obsidian. 

### Excalidraw: 
Simply install this program and have it outside of the folder, add links and move it to the respective folder inside master when your finished writing the notes. This just functions as any other note inside obsidian, but handwritten. Lectures in Physics are hard to write in LaTeX or plain text, and I find I recall and learn better this way. 

### Tasks 
Install Tasks and then create a file called "tasks" inside this task place the following code:
```tasks
group by function { \
    let cacheKey = 'filename-heading-normalised-urgency'; \
    let getTaskGroup = (t) => (t.file.filenameWithoutExtension || "") + (t.heading ? "#" + t.heading : ""); \
    if (!query.searchCache[cacheKey]) { \
        let allTasks = query.allTasks.filter(t => !t.isDone); \
        let groupUrgencyMap = new Map(); \
        let groupTaskCountMap = new Map(); \
        allTasks.forEach(t => { \
            let taskGroup = getTaskGroup(t); \
            groupUrgencyMap.set(taskGroup, (groupUrgencyMap.get(taskGroup) || 0) + (t.urgency || 0)); \
            groupTaskCountMap.set(taskGroup, (groupTaskCountMap.get(taskGroup) || 0) + 1); \
        }); \
        let normalize = (group) => groupUrgencyMap.get(group) / (groupTaskCountMap.get(group) || 1); \
        let sortedGroups = [...groupUrgencyMap.keys()].sort((a, b) => { \
            let na = normalize(a), nb = normalize(b); \
            if (isNaN(na) && isNaN(nb)) return 0; \
            if (isNaN(na)) return 1; \
            if (isNaN(nb)) return -1; \
            return nb - na; \
        }); \
        query.searchCache[cacheKey] = { sortedGroups, normalize }; \
    } \
    let { sortedGroups, normalize } = query.searchCache[cacheKey]; \
    let taskGroup = getTaskGroup(task); \
    let index = sortedGroups.indexOf(taskGroup); \
    return taskGroup ? '%%' + (isNaN(normalize(taskGroup)) ? Number.MAX_SAFE_INTEGER : index) + '%% [[' + taskGroup + ']] (Normalized Urgency: ' + (isNaN(normalize(taskGroup)) ? 'N/A' : normalize(taskGroup).toFixed(2)) + ')' : ''; \
}
```
This does a "normalised urgency" and makes a to do list of all your tasks across all of your notebooks. If I need to do a task I will add it into the relevant note as this "tasks" note keeps track of everything in one place.
