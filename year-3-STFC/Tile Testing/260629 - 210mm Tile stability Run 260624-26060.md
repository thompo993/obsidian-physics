# procedure 

- 210mm tile was coupled to the PMT rig 
- chB+D is recorded (default by list mode and cannot be changed)
- sr90 source inserted and run set on list mode 
- this does a log of pulse height against time, which I then investigated.
- **note, its not definitely a power surge, but a suspected power surge**
